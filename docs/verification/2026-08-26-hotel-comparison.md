价格以“分”保存为 3 晚含税快照总额；不同晚数按快照总额的比例计算后才舍入到分，不会将已四舍五入的每晚价重复相乘。它只能用于相对比较，不能作为下单承诺。早餐、取消条件和车站步行描述均限于同一参考快照或来源页面，卡片明确提示以实际订单页为准。

通勤行按当前香港日、当天首末地点和所选酒店坐标向高德路线服务请求。只展示服务返回的时间、距离和核查时间；没有返回时显示“待高德路线确认”，绝不以几何距离或步数估算代替。酒店地图会使用高德 JS API 的真实坐标标记；浏览器凭据未配置或加载错误时显示诚实的降级提示与可访问标记列表。

# 旅行通行证主界面设计

## 目标

将登录后首页从功能面板收口为与登录页一致的“旅行通行证”体验。保留现有行程、成员、酒店、预算、订单与编辑功能，不改变数据模型或操作含义。

## 已确认的视觉方向

- 视觉主题：旅行通行证；米白纸张、深绿主文字、橙红仅用于路线、日期印章和危险操作。
- 首屏构图：左侧编辑感叙事，右侧竖向通行证；不使用居中的后台卡片布局。
- 标题文案：`两个人，` / `一条向南的路线。`
- 路线叙事：北京出发，深圳、香港、澳门、珠海，最后回到北京。

## 路线组件

- 站点顺序固定为 `PEK 北京 → SZX 深圳 → HKG 香港 → MFM 澳门 → ZUH 珠海 → PEK 北京`。
- 使用深绿虚线的连续波浪 SVG 路径；各站点放在波峰或波谷。
- 起点和终点北京使用橙红描边，其他节点使用深绿描边。
- 最后一段从珠海拉开后抵达北京；路径在北京终点圆环中心收束，终点右侧没有线段。

## 右侧通行证

- 票头：`TRIP PASS` 与 `PRIVATE JOURNEY`。
- 首段仅展示当前第一日航段：`PEK 北京出发 → SZX 第一站·深圳`，不使用误导性的 `PEK → PEK`。
- 中部展示 `D1 · 10 月 03 日` 与当前旅行状态；底部包含成员名、编号和橙红日期印章。
- 票根使用细虚线分隔与左右半圆缺口；避免额外大面积阴影和渐变。

## 行程与操作

- 首屏下方使用“ROUTE MANIFEST / 每日计划”，日期以窄票签连续排列；当前日期使用浅绿底和橙红当前标识。
- 行程操作为无底色的印刷控制栏：新增为深绿主操作，复制为低强调中性操作，删除为低强调橙红文字；不使用圆角胶囊按钮。
- 酒店比较、成员、退出置于顶部文字导航，使用下划线选中态或小型印刷标识，不堆叠成按钮组。
- 当天计划与预算保留在首屏下一段，采用细分隔线和开放留白，不额外套厚重卡片。

## 响应式

- 桌面优先：左叙事 / 右票根双栏。
- 窄屏：叙事在上、票根在下；路线可横向完整呈现或按比例缩放，不能截断终点。
- 日期票签横向滚动，控制栏保持文字操作；顶部文字导航在窄屏缩为菜单或次级区域。

## 验收标准

1. 首页第一屏与登录页共享同一纸张、票根、印章、深绿和橙红语言。
2. 路线准确表达北京出发、北京返程，终点无延长线。
3. 所有现有首页操作仍可点击，且视觉上不再呈现为通用后台胶囊按钮。
4. 桌面与窄屏没有内容截断、文字溢出或路线节点重叠。

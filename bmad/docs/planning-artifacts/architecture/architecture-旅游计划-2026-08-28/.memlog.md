- (direction) 快速路径：以现有 React/Vite、CloudBase、Trip API 和 TypeScript contracts 为现实约束，产出 build substrate。
- (constraint) PRD FR-1 至 FR-9、无交易、前端无密钥/Cookie、Desktop 离线时 PWA 可读为本架构的绑定约束。
- (constraint) 现有 packages/contracts 的 TripSchema 和 TripRepository 是整份行程的乐观版本保存；functions/trip-api 以 CloudBase 运行时身份授权，database.rules.json 禁止直接写入。
- (decision) 决策协作层采用并列集合和资源级 revision，不扩展或替换现有 TripSchema；通过 trip-api 命令写入，避免整份 Trip 保存造成静默覆盖。
- (decision) 候选的证据可信度与用户决策状态分离：verificationState 表达 candidate/web_verified/needs_takeover/stale，decisionState 与两人确认回执表达 tentative/confirmed。
- (decision) Desktop Agent 只持有用户显式启动的短期、单行程、最小权限写回令牌；只能提交候选和证据批次，不能变更偏好、成员、反馈、暂定或最终确认。
- (decision) 成员移除级联更新所有可读决策文档的 memberUids 并清除该客户端本地决策缓存，防止旧 ACL 副本继续授权。
- (decision) Agent Run 使用每次运行公钥和签名挑战，不经前端交接 bearer token；Agent 对每个规范化命令证明私钥持有。
- (decision) 暂定摆放是 Candidate 的独立字段 tripDayId/date/sortKey；与既有 Trip itemIds 的落地关联保留为显式后续命令。
- (event) spine finalized after independent contract-integrity review
- (decision) Decision collections are server-private and omit memberUids; workspace reads/reconnect use trip-api cursor events with canonical membership checks, tombstones, and CURSOR_EXPIRED full reload.
- (decision) Agent Bridge protocol is fixed: P-256 ES256 per-run key, SHA-256 pairing-code hash, authenticated create, local claim, monotonic signed sequence, 15-minute expiry, and no bearer credential.
- (decision) TentativePlacement is a first-class resource; attach/detach changes it and legacy Trip.itemIds atomically with dual CAS, while confirmation requires active planned/linked placement and derives rollback.
- (decision) Web verification is service-derived from web/official detail-page evidence with per-category required fact keys and expiry predicates.
- (event) contract-integrity review revised to approved for implementation
